# Lab 3 — 내 요청문으로 휴가 신청 스킬을 만들고 팀에 넘기기

## 목표

팀에서 Claude Code로 연차 조회·신청을 처리하려 합니다 -- 그 스킬 `leave-request`를 만듭니다. 이번에는 요청문도 **내가 씁니다**. 먼저 HR 시스템을 그냥 불러 무엇이 돌아오는지 보고, 초안을 쓰고, lab2에서 만든 `/prompt-coach`로 다듬고, 다듬은 요청문을 그대로 붙여 스킬을 만들고, 실제로 세 번 실행해 본 뒤, 팀이 받아 바로 쓸 수 있게 정리해 토큰 없는 커밋으로 넘깁니다.

| 구분 | 내용 |
|---|---|
| 생성 에셋 | 다듬은 요청문(`docs/prompts/leave-request.md`에 저장) · `.claude/skills/leave-request/SKILL.md`(팀원이 바로 쓸 수 있게 정리) · README 맨 위 세 줄 · 커밋 1개 |
| 호출 | `/leave-request …` -- 인자 모양은 내가 정한다(예: 조회는 인자 없이, 신청은 `신청 <직원> <날짜> <일수>`) |
| 연결 | HR 시스템은 준비 명령으로 이미 연결되어 있다 -- `/mcp`에 `hr`. 인증·API 코드는 쓰지 않는다 |
| 완료 기준 | 조회가 되고, 신청 1건이 접수 ID로 보이고, 내가 "일어나면 안 되는 일"로 정한 것 하나를 실제로 시도해 신청이 생기지 않았다 |

## 파일 구조

```text
superlab/
├── .mcp.json, tools/hr_mcp.py          HR 시스템 연결 (준비 명령이 저장한 토큰을 환경 변수에서 읽는다)
├── .claude/settings.json               조회 도구는 승인 없이, 신청 도구는 승인 창 -- 바꾸지 않는다
├── .claude/skills/prompt-coach/        lab2에서 만든 내 도구
├── .claude/skills/leave-request/       ★ 이 랩에서 만드는 스킬
├── docs/prompts/leave-request.md       ★ 다듬은 요청문 (초안 → 질문과 답 → 최종)
└── README.md                           ★ 맨 위 세 줄 -- 무엇을 하는 저장소인지 · 처음 칠 명령 · 하면 안 되는 것
```

## 진행

참가자가 치는 것은 **자연어 조회 3번, 초안 1개, 질문 답 ≤3, 붙이기 1번, 실행 3번(승인 2번), 넘기기 지시 1줄**입니다.

| 단계 | 내가 하는 것 | 확인 |
|---|---|---|
| 1 연결 보기 | `/mcp` -> `hr`를 고르면 도구 4개가 보인다. 그다음 자연어로 세 번 부른다: `팀 연차 현황 조회해 줘` / `kim 연차 조회해 줘` / `신청 내역 조회해 줘` | 승인 창 없이 바로 돌아온다. 팀 조회는 직원·역할·총·사용·잔여가 든 자료, 직원 조회는 "kim님의 연차는 총 15일, 사용 9일, 잔여 6일입니다" 한 문장. **이 재료로 스킬을 만든다** |
| 2 초안 쓰기 | 위 표와 1단계에서 본 것으로 요청문 초안을 3~6줄 쓴 뒤 "이 초안을 `docs/prompts/leave-request.md`에 저장해 줘"라고 한다. 잘 쓰려 하지 않는다 -- 다음 단계가 고친다 | 파일이 생겼다 |
| 3 다듬기 | `/prompt-coach docs/prompts/leave-request.md` -> 질문에 답한다(한 번에 하나, 선택지 또는 직접) -> 고친 요청문을 받는다. "질문과 답, 최종 요청문을 같은 파일에 덧붙여 줘"라고 한다 | 질문에 "읽는 사람", "일어나면 안 되는 일", "출력 형식" 중 둘 이상이 나오면 정상 -- 누가 쓰는지, 무엇이 일어나면 안 되는지, 결과 모양은 여기서 내가 정한다 |
| 4 만들기 | 최종 요청문을 **그대로** 붙인다 | `.claude/skills/leave-request/SKILL.md` 생성(쓰기 승인 1회) |
| 5 실행 3회 | ① 조회 ② 신청 1건 -> 승인 창 -> **허용** ③ 신청을 다른 날짜로 -> 승인 창 -> **거절** | ① 결과가 1단계에서 본 자료와 같다 ② 접수 ID가 나오고 `신청 내역 조회해 줘`에 그 ID가 보인다 ③ 거절한 건은 내역에 없다 |
| 6 팀에 넘기기 | 아래 "팀에 넘기기"의 한 줄을 Claude에게 시킨다 | `git show --stat`에 README와 스킬만 있고 토큰 파일이 없다 |

3단계에서 내가 "일어나면 안 되는 일"로 답한 것 하나를 5단계에서 실제로 시도해 봅니다(예: 날짜를 빼고, 일수를 99로). 신청이 생기면 안 됩니다. 어디서 막혔는지(스킬이 먼저 / 시스템이 거절 / 내가 승인 창에서)는 정답이 없습니다 -- 생기지 않았으면 됩니다. 승인 창은 저장소 설정이 보장하므로, 내가 아무것도 정하지 않았어도 전송 직전에 멈출 자리는 남습니다.

## 팀에 넘기기 (6단계)

스킬을 팀과 공유하는 공식 방법은 셋입니다 -- 저장소의 `.claude/skills/`를 커밋한다(그 저장소에서 세션을 여는 모두가 받는다) / 플러그인으로 묶는다 / 조직 관리 설정으로 배포한다. 이 랩은 첫 번째입니다: 커밋 하나가 넘기는 단위이고, 아래 한 줄을 Claude에게 시키면 끝입니다.

```
leave-request를 팀에 넘길 거야. SKILL.md에 내 이름·컴퓨터 경로·토큰이 없는지 봐 줘. 그리고 README 맨 위에 세 줄을 적어 줘 -- 이 저장소가 무엇을 하는 곳인지, 받은 사람이 처음 칠 명령, 하면 안 되는 것. 다 되면 커밋해.
```

토큰 파일(`.claude/settings.local.json`)과 `usage.csv`는 `.gitignore`가 막습니다 -- `git show --stat`에 없는지 한 번 봅니다.

## 초안 예 (2단계)

```
휴가 신청 스킬 leave-request를 만들어 줘. /leave-request 치면 팀 연차 현황표가 나오고, 신청 kim 2026-10-07 1 처럼 치면 hr 도구로 신청까지 해 줘. 날짜 빠지면 물어봐.
```

## 시간이 남으면

기능을 하나 더해 보세요 -- 예: 반차(0.5일), 신청 취소, 팀장용 요약 한 줄. 원하는 것을 `docs/prompts/leave-request.md`에 덧붙여 `/prompt-coach`로 다듬고 스킬에 반영합니다. 무엇이 바뀌었는지 세 줄과 함께 워크숍 슬랙 채널에 공유해 주세요. 다른 팀 것을 내 저장소에 가져가도 됩니다.

## 알아 두면 좋은 것

- 신청에는 **늘 승인 창이 뜹니다.** 저장소 설정이 신청 도구를 "승인"으로 두었고, 승인 규칙은 deny → ask → allow 순서라 스킬 머리 부분에 무엇을 적어도 승인 창이 남습니다. 요청문에 "보내기 전에 확인"을 적었다면 승인 창 앞에 스킬의 확인 한 줄이 한 번 더 나옵니다 -- 두 층입니다.
- 신청 내역에는 같은 실습 토큰을 쓰는 다른 참가자의 신청도 함께 보입니다. 내 것은 접수 ID로 찾습니다.
- 실행하다 보면 부딪히는 것 둘: HR 시스템은 "나"가 누구인지 모르니 직원 이름이 필요하고, 날짜를 "10월 7일"처럼 쓰면 스킬이 어떻게 받을지 정해져 있어야 합니다. 부딪혔으면 6단계 전에 내 도구로 한 번 더 다듬습니다 -- 그것이 "시간이 남으면"의 첫 소재입니다.
- 토큰은 `.claude/settings.local.json`에만 있고 커밋되지 않습니다. 스킬·요청문·README에 토큰을 적을 일은 없습니다.
- 공용 HR 시스템이 응답하지 않으면: `python3 tools/lab_server.py` → `LAB_API_BASE=http://127.0.0.1:8787 bash tools/setup.sh` → Claude Code 다시 시작. 스킬은 그대로 동작합니다.

## 막힐 때

- 초안이 안 나온다: "hr 도구로 연차 조회하고 신청하는 스킬 leave-request를 만들어 줘" 한 줄이 초안이다. 얇아도 된다 -- 그다음은 `/prompt-coach`가 묻는다.
- 신청에서 승인 창이 안 뜬다: 저장소 설정이 바뀐 것이다. 강사에게 알린다.
- 공용 HR 시스템이 응답하지 않는다: 다른 터미널에서 `python3 tools/lab_server.py`를 켜 두고, `LAB_API_BASE=http://127.0.0.1:8787 bash tools/setup.sh`를 한 번 돌린 뒤 Claude Code를 다시 시작한다. 토큰은 그대로, 스킬도 그대로 동작한다.
