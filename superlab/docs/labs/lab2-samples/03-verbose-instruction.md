# 샘플 03 -- 사족이 많은 지시

## 입력

```
너는 20년 경력의 세계 최고 코드 리뷰어다. 심호흡을 하고, 매우 신중하게 step by step으로 깊이 생각해서 src/ 아래 코드를 빠짐없이 철저하게 리뷰해. 다만 심각도가 높은 것만 보고하고 확신 없는 건 빼. 리뷰 전에 네가 생각한 과정을 먼저 전부 적어.
```

## 기대 지적 (최소)

1. **싸우는 문장을 가장 먼저** -- "빠짐없이 철저하게" + "심각도 높은 것만 보고하고 확신 없는 건 빼": 모델이 검토 범위까지 줄여 실제 문제가 빠질 수 있다. 검토는 전부 하게 하고, 보고 범위(심각도 기준)는 사용자에게 묻는다 -- 사용자가 원한 "심각한 것만 보고"는 유지한다.
2. **모델이 이미 하는 일을 뺀다** -- "심호흡", "매우 신중하게", "step by step", "깊이 생각해서", "20년 경력 세계 최고"(과장 수식). 뺀 자리에 대체 규칙을 넣지 않는다.
3. **"생각한 과정을 먼저 전부 적어"는 뺀다** -- 거절될 수 있는 요청(`reasoning_extraction`). 짧은 설명 요청으로 바꾸거나 삭제.

고친 요청문은 원본보다 짧아야 하고, 역할 한 문장("코드 리뷰어")은 남겨도 된다.
