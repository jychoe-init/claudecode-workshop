# lab2 샘플 -- 내가 만든 prompt-coach를 시험하는 입력 세 개

각 파일의 윗부분이 `/prompt-coach`에 넣는 입력이고, 끝의 "기대 지적"은 내 도구가 **최소한** 집어야 하는 것이다. 기대 지적은 통과 기준이지 정답 전부가 아니다 -- 더 집어도 된다. 하나라도 빠지면 SKILL.md를 고치고 그 샘플만 다시 돌린다.

| 샘플 | 시험하는 것 |
|---|---|
| `01-hr-skill-request.md` | 빠진 것 넷을 질문·보완으로 집는가 (lab3에서 실제로 쓸 요청문의 나쁜 판) |
| `02-meeting-notes.md` | 읽는 사람·출력 형식이 없을 때 묻는가, 붙여 넣은 자료를 지시와 구분하는가 |
| `03-verbose-instruction.md` | 모델이 이미 하는 일을 빼고, 싸우는 문장을 먼저 지적하는가 |

돌리는 법: 입력 블록을 그대로 인자로 넣는다. 예: `/prompt-coach "hr 도구로 연차 조회하고 신청하는 스킬 만들어 줘. 이름은 leave-request. 알아서 잘 해 줘."`
