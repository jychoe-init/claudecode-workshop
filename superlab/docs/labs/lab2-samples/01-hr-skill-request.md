# 샘플 01 -- HR 휴가 스킬 요청문 (나쁜 판)

## 입력

```
hr 도구로 연차 조회하고 신청하는 스킬 만들어 줘. 이름은 leave-request. 알아서 잘 해 줘.
```

## 기대 지적 (최소)

1. **읽는 사람·용도가 없다** -- 누가 `/leave-request`를 쓰고 결과를 누가 읽는가(팀장 보고인가, 본인 확인인가). 질문 또는 가정으로 나와야 한다.
2. **일어나면 안 되는 결과가 없다** -- 잔여보다 많은 신청, 날짜가 빠진 신청, 데이터에 없는 사람이 보고에 나오는 것. "신청"은 바꾸는 일이므로 보내기 전 확인이나 승인에 대한 언급이 없다는 지적.
3. **출력 형식이 없다** -- 현황표의 열, 신청 결과를 어떻게 보여 줄지.
4. **"알아서 잘 해 줘"는 정보가 없다** -- 뺀다(또는 구체 요구로 바꾼다).

판정은 "손볼 데 있음" 또는 "처음부터 다시 쓰는 게 빠름"이어야 한다. "그대로 써도 됨"이면 실패.
