워크샵 사내 API

Claude Code 워크샵 실습용 가짜 HR·배포 시스템입니다. 모든 데이터는 가짜이며 실습은 공통 토큰 하나를 함께 써서 모두 같은 팀 데이터를 봅니다. 기본 주소는 이 페이지의 주소와 같습니다(https://<이 호스트>/v1/...).

인증: 모든 /v1/* 요청에 Authorization: Bearer lab-xxxxxxxx 헤더. 토큰은 배부받은 것을 쓰고, 저장소에 커밋하지 않습니다(.claude/settings.local.json의 env.LAB_TOKEN).

엔드포인트

메서드·경로설명응답 예
GET /v1/me내 토큰의 팀과 구성원
{"token_hint":"lab-…","team":"payments",
 "members":[{"employee":"kim","role":"backend"}, …]}
GET /v1/leave팀 연차 현황
{"team":"payments","as_of":"2026-10-20",
 "balances":[{"employee":"kim","role":"backend",
   "annual":15,"used":6,"remaining":9}, …]}
GET /v1/leave/{직원}구성원 한 명의 연차
{"team":"payments","employee":"kim",
 "annual":15,"used":6,"remaining":9}
GET /v1/leave/requests신청 목록(최근 20건. 공통 토큰이라 모두의 신청이 보입니다)
{"team":"payments","requests":[…]}
POST /v1/leave/requests연차 신청(변경 동작). 본문 {"employee","date","days"}
201 {"request_id":"REQ-01234","employee":"kim",
 "date":"2026-10-30","days":1,"status":"pending"}
GET /v1/mail/{메일함}/sent
GET /v1/mail/sent		직무별 실습 메일함(planning 기획·운영 · sales 영업 · cs CS · hr 인사, 생략하면 planning)에서 보고 주에 보낸 메일 7통(Microsoft Graph message 형식)
{"value":[{"subject":"[요청] 하반기 마케팅 예산 집행 승인",
 "sentDateTime":"2026-09-29T02:10:00Z",
 "toRecipients":[{"emailAddress":{"name":"kim", …}}],
 "bodyPreview":"…", …}]}
GET /v1/calendar/{메일함}
GET /v1/calendar		보고 주 일정 5건과 오늘 뒤 근무일 일정 2건(Microsoft Graph event 형식). 보고 주는 금~일이면 이번 주, 월~목이면 지난주
{"value":[{"subject":"사업기획팀 주간 정례",
 "start":{"dateTime":"2026-09-28T10:00:00","timeZone":"Asia/Seoul"},
 "attendees":[…], …}]}
GET /v1/deploys서비스별 배포 상태(개발 트랙용)
{"team":"payments","deploys":[{"service":"order-api",
 "version":"v3.12.4","status":"healthy", …}]}

오류

코드뜻
401 unauthorized헤더가 없거나 토큰 형식이 아님
403 invalid_token등록되지 않았거나 만료된 토큰
404 unknown_employee내 팀 구성원이 아님
404 unknown_mailboxplanning·sales·cs·hr 이외의 메일함
409 insufficient_balance잔여보다 많이 신청
429 rate_limited토큰당 분당 3000회 초과

Claude Code 스킬에서 쓰기

킷의 tools/hr_fetch.py가 이 API를 호출해 JSON을 출력합니다. 스킬 첫 줄에서 주입하면 됩니다.

!`python3 tools/hr_fetch.py leave`        # GET /v1/leave
!`python3 tools/hr_fetch.py deploys`      # GET /v1/deploys
!`python3 tools/hr_fetch.py me`

킷 기본 울타리가 curl을 차단하므로 스크립트로 호출합니다. 스크립트는 조회(GET)만 합니다. 공용 주소가 막히면 LAB_API_BASE=http://127.0.0.1:8787로 바꾸고 python3 tools/lab_server.py를 켜면 같은 응답을 받습니다.

터미널에서 확인(참고)

python3 - <<'EOF'
import json, os, urllib.request
req = urllib.request.Request(os.environ.get("LAB_API_BASE", "https://이-호스트") + "/v1/me",
                             headers={"Authorization": "Bearer " + os.environ["LAB_TOKEN"]})
print(json.dumps(json.load(urllib.request.urlopen(req)), ensure_ascii=False, indent=2))
EOF
